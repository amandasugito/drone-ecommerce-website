# 🚁 JCI Drone Store Website — Human-Computer Interaction

## 📌 Project Overview

This project is a Human-Computer Interaction (HCI) website project for JCI, a drone-focused brand concept featuring the Skyvision X7 Pro.

The website was designed to provide users with an organized interface to explore drone products, discover community discussions, find purchasing platforms, and contact the store.

## 🎯 Project Objectives

- Design a clear and user-friendly website interface.
- Organize drone products and purchasing information.
- Provide access to a drone enthusiast community forum.
- Implement client-side contact form validation.
- Apply HCI principles to website navigation and interaction design.

## 🖥️ Website Pages

### 🏠 1. Home Page

Introduces the Skyvision X7 Pro through a product headline, subtitle, product imagery, and a Buy Now call-to-action. It also features a product demonstration video, company achievements, expertise, navigation links, and footer information.

### 🛍️ 2. Products Page

Presents drone products with a search interface and product listings organized by type.

### 💬 3. Community Forum

Displays trending topics and community posts related to drones, photography, firmware updates, and flight experiences.

### 🛒 4. Store Page

Provides purchasing options through the JCI official app concept, Apple App Store, Google Play, Shopee, and Tokopedia.

### 📩 5. Contact Page

Contains store contact information and a message form with client-side validation for required fields, phone number format, email format, and terms agreement.

## ⚙️ Features

- Multi-page website navigation.
- Product-focused landing page.
- Product catalog and search interface.
- Community forum layout.
- External purchasing links.
- Contact form validation using JavaScript.
- Responsive navigation menu interaction.

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `Project/index.html` in a web browser.
4. Navigate through the available website pages.

No backend server is required for the current static website implementation.
